## 🛠️ First-Time Setup (Do This Once)

### Step 1 — Change your password
1. Log in at https://sallonart.vercel.app/login
2. Click your name (top right) → **Profile**
3. Click **Change Password** → enter new password
4. ✅ Done

### Step 2 — Set your operating hours
1. Menu → **Operating Hours**
2. For each day, set Open / Close times
3. Toggle any day to **CLOSED** if you're shut (e.g., Sunday)
4. Shortcut: Use **"Apply to weekdays (Mon–Fri)"** to set all weekdays at once
5. Click **Save Changes**

### Step 3 — Review categories & services
The system comes with sample salon data:
- **3 categories:** Hair, Beard & Shave, Facial & Cleanup
- **14 services:** Haircut, Beard Trim, Classic Facial, etc.
- **6 combo packages:** Groom Package, Royal Grooming, Complete Makeover, etc.

You can:
- **Edit prices** — Menu → Manage Services → Edit pencil → change price
- **Deactivate** — Click the green "Active" badge to hide a service
- **Delete** — Click Delete button
- **Add new** — Click `+ Service` or `+ Package`

## 📅 Daily Use — Managing Bookings

### When a customer books online
1. You'll see it in **Dashboard** and **Bookings**
2. Status starts as **Pending** or **Confirmed**
3. Click the **phone number** on any booking to call the customer
4. After the service, mark it as **Completed**

### Taking walk-in / phone bookings yourself
1. Menu → **Quick Booking**
2. Enter customer name + mobile number
3. Pick service, date, time
4. Click **Book** → confirmation saved

### Cancelling a booking
1. Open **Bookings** page
2. Find the booking → click **Cancel**
3. The time slot opens back up for other customers
